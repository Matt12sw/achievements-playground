# Contributing

Contributions are welcome! Whether you want to improve a script, add support for another shell, fix a typo, or update badge requirements if GitHub changes them, feel free to jump in.

## How to Contribute

1. Fork this repository.
2. Create a feature branch (`git checkout -b feat/your-improvement`).
3. Commit your changes (`git commit -m "Add your improvement"`).
   - Tip: If you are working with someone else, add a `Co-authored-by:` trailer at the end of your commit message.
4. Push to your branch (`git push origin feat/your-improvement`).
5. Open a Pull Request describing what you changed and why.

## Guidelines

- Keep scripts readable, safe, and respectful of GitHub API rate limits.
- Never commit personal access tokens or credentials.
- Document any new script parameters in both `README.md` and `README_FR.md`.
